# DeskBuddy

เพื่อนตัวเล็ก ๆ บน Windows ที่คอยทักตามจังหวะที่เหมาะสม ไม่ใช่แค่ตัวเตือน

- จับเวลาเล่นเกมแยกตามเกม (ดูจากชื่อ process)
- เล่นนานเกินเกณฑ์ (ค่าเริ่มต้น 2 ชั่วโมง) แล้วถามว่าจะพักไหม **โดยรอให้คุณหยุดขยับเมาส์/คีย์บอร์ดก่อน** จึงไม่ขัดจังหวะตอนกำลังเล่น
- ถ้าไม่ได้เล่นเกม ทักเรื่องกินข้าว เช้า / เที่ยง / เย็น และทักเรื่องนอนตอนดึก
- Minecraft: ถ้าตายซ้ำ ๆ ในเวลาสั้น ๆ จะทักถามว่าพักไหม (อ่านจากไฟล์ log ของเกม ดูหัวข้อด้านล่าง)
- ทักไม่จู้จี้: จำกัดจำนวนครั้งต่อวัน เว้นระยะระหว่างข้อความ และถ้ากดปิดข้อความที่ถามเกิน 3 ครั้ง วันนั้นจะเงียบ
- ผู้ใช้ตอบด้วยปุ่ม ไม่ต้องใช้เน็ตและไม่ใช้ AI
- ข้อมูลทั้งหมดเก็บในเครื่อง (`data/stats.json`) ไม่ส่งออกไปไหน

## ติดตั้งและรัน

ต้องมี Python 3.10 ขึ้นไป (ติดตั้งแบบมี tkinter ซึ่งตัวติดตั้งปกติจาก python.org มีให้อยู่แล้ว)

```
pip install -r requirements.txt
python main.py
```

โปรแกรมจะไปอยู่ที่ไอคอนหน้ายิ้มสีส้มใน system tray (มุมขวาล่าง อาจอยู่ใต้ลูกศร ^) คลิกขวาเพื่อ:

| เมนู | ทำอะไร |
|---|---|
| ตั้งค่า… (หรือดับเบิลคลิกที่ไอคอน) | เปิดหน้าต่างตั้งค่า |
| ดูสถิติวันนี้ | เวลาเล่นแต่ละเกมของวันนี้ |
| พักการแจ้งเตือน 60 นาที / เปิดอีกครั้ง | ปิดเสียงชั่วคราว |
| เปิดพร้อม Windows | ติ๊กเองเท่านั้น โปรแกรมไม่ตั้งตัวเองเข้า Startup |
| ออกจากโปรแกรม | |

ถ้าไม่อยากให้มีหน้าต่างดำค้างอยู่ ให้รันด้วย `pythonw main.py` แทน

## หน้าต่างตั้งค่า

คลิกขวาที่ไอคอนใน tray เลือก "ตั้งค่า…" (หรือดับเบิลคลิกที่ไอคอน) มี 4 แท็บ กด "บันทึก" แล้วใช้ค่าใหม่ทันที ไม่ต้องรีสตาร์ต

| แท็บ | ตั้งอะไรได้ |
|---|---|
| ทั่วไป | ชื่อที่ให้เพื่อนเรียก, บุคลิก, เปิดพร้อม Windows |
| มื้ออาหาร / นอน | เปิด-ปิดและช่วงเวลาของมื้อเช้า/เที่ยง/เย็น และช่วงที่ทักเรื่องนอน |
| เกม | เพิ่ม/ลบเกม, ชื่อ process, ชื่อหน้าต่าง, ชื่อตัวละคร Minecraft ปุ่ม "เลือกจากโปรแกรมที่กำลังรัน" ช่วยหาชื่อ process โดยไม่ต้องเปิด Task Manager |
| ทดสอบ | ปุ่มเรียกป๊อปอัปมาดูทันที: ทักทายตอนเปิดเครื่อง (เช้า/กลางวัน/เย็น/ดึก/กลับมาหลังหายไปหลายวัน), ถามกินข้าว 3 มื้อ, ถามพัก, ตายซ้ำ, ทักเรื่องนอน |

ปุ่มทดสอบไม่นับเป็นข้อความของวัน ไม่บันทึกคำตอบ และไม่กระทบเวลาเตือนจริง ลองกดปุ่มตอบในป๊อปอัปเพื่อดูคำตอบของเพื่อนได้ด้วย ป๊อปอัปตัวอย่างใช้ชื่อและบุคลิกที่ **บันทึกแล้ว** ถ้าเพิ่งแก้ให้กด "บันทึก" ก่อน

ค่าอื่นที่ยังไม่มีในหน้าต่าง (เช่น เล่นนานกี่ชั่วโมงถึงทัก, เพดานข้อความต่อวัน) แก้ที่ `config.json` ตามหัวข้อถัดไป

## ตั้งค่าด้วยไฟล์ config.json

ครั้งแรกที่รัน โปรแกรมจะสร้าง `config.json` ให้ แก้ได้เลย ไม่ต้องใส่ครบทุกค่า ค่าที่ไม่ระบุจะใช้ค่าเริ่มต้น (ถ้าแก้ไฟล์ขณะโปรแกรมรันอยู่ ต้องออกจากโปรแกรมแล้วเปิดใหม่ และอย่าให้หน้าต่างตั้งค่าเปิดค้างไว้ เพราะตอนกดบันทึกมันจะเขียนทับด้วยค่าที่เห็นในหน้าต่าง) ตัวอย่าง:

```json
{
  "user_name": "สุข",
  "break_after_minutes": 90,
  "max_popups_per_day": 6
}
```

ค่าที่น่าปรับ:

| ค่า | ความหมาย |
|---|---|
| `user_name` | ชื่อที่ให้เพื่อนเรียก (ถ้าว่าง จะไม่ใช้ข้อความที่ต้องเรียกชื่อ) |
| `break_after_minutes` | เล่นต่อเนื่องกี่นาทีถึงถามพัก (ค่าเริ่มต้น 120) |
| `idle_wait_seconds` | ต้องว่างกี่วินาทีก่อนขึ้นข้อความ (15) |
| `break_reset_idle_minutes` | ว่างนานเท่านี้ถือว่าได้พักแล้ว นับใหม่ (5) |
| `max_popups_per_day` / `min_gap_minutes` | เพดานต่อวัน / ระยะห่างขั้นต่ำระหว่างข้อความ (8 / 20) |
| `meals` / `meals_enabled` | ช่วงเวลามื้ออาหาร / เปิด-ปิดแต่ละมื้อ |
| `late_night` | ช่วงเวลาที่ทักเรื่องนอน (`"enabled": false` เพื่อปิด) |

## เพิ่มเกม

ทำได้ที่แท็บ "เกม" ในหน้าต่างตั้งค่า หรือแก้ `games.json` เองก็ได้ ต้องใส่ชื่อ process ที่ตรงกับในเครื่องคุณ วิธีหา: เปิดเกม → กดปุ่ม "เลือกจากโปรแกรมที่กำลังรัน" ในหน้าตั้งค่า หรือเปิด Task Manager → แท็บ Details → ดูชื่อ `.exe` ของเกม

```json
{ "name": "ชื่อเกมที่อยากให้แสดง", "process": "ชื่อไฟล์.exe" }
```

ชื่อ process ในไฟล์ตัวอย่างเป็นการคาดเดาจากความรู้ทั่วไป **ยังไม่ได้ตรวจกับเครื่องจริง** บางเกมอาจชื่อไม่ตรงและต้องแก้เอง

## Minecraft (Java Edition)

Minecraft Java รันผ่าน `javaw.exe` ซึ่งโปรแกรม Java อื่นก็ใช้ชื่อเดียวกัน จึงตั้งให้นับเป็น Minecraft เฉพาะเมื่อมีหน้าต่างที่ชื่อมีคำว่า "Minecraft"

ถ้าอยากให้ทักตอนตายซ้ำ ๆ ให้ใส่ชื่อตัวละครใน `games.json`:

```json
"death_log": {
  "path": "%APPDATA%\\.minecraft\\logs\\latest.log",
  "player": "ชื่อตัวละครของคุณ"
}
```

โปรแกรมอ่านเฉพาะไฟล์ log ที่เกมเขียนเอง ไม่ยุ่งกับหน่วยความจำของเกมและไม่ส่งผลกับระบบกันโกง

ข้อจำกัดที่ควรรู้:
- ใช้กับ Java Edition เท่านั้น (Bedrock ไม่ได้)
- ถ้าใช้ตัวเปิดเกมอื่น (Prism, MultiMC ฯลฯ) ไฟล์ log จะอยู่คนละที่ ต้องแก้ `path`
- รายการข้อความตายใน `deskbuddy/minecraft_log.py` ยังไม่ครบทุกแบบ ถ้าตายแล้วไม่ถูกนับ ให้เพิ่มวลีใน `DEATH_PHRASES`
- ทดสอบกับข้อความ log ตัวอย่างเท่านั้น ยังไม่ได้ทดสอบกับเกมจริง

## เพิ่ม/แก้บุคลิก

ข้อความทั้งหมดอยู่ใน `personalities/friendly.json` แยกตามสถานการณ์ แต่ละสถานการณ์มีหลายประโยค โปรแกรมสุ่มและไม่ซ้ำประโยคเดิมติดกัน ตัวแปรที่ใช้ได้: `{name}` `{game}` `{duration}` `{count}`

อยากทำบุคลิกใหม่ ให้คัดลอกไฟล์เป็นชื่อใหม่ (เช่น `teasing.json`) แก้ข้อความ แล้วตั้ง `"personality": "teasing"` ใน `config.json` ต้องมีครบทุกสถานการณ์ ไม่งั้นโปรแกรมจะแจ้งว่าขาดอะไร

## ทดสอบ

```
python -m unittest discover -s tests -v
```

เทสต์ครอบคลุมตรรกะการตัดสินใจ (ส่วนที่ไม่ผูกกับ Windows) ส่วนที่เรียก Windows โดยตรง (ตรวจ idle, system tray, Startup) ต้องลองบนเครื่องจริง

## สร้างเป็น .exe (ไม่บังคับ)

```
pip install pyinstaller
pyinstaller --onefile --noconsole --name DeskBuddy main.py
```

แล้ววางไฟล์ `games.json` กับโฟลเดอร์ `personalities/` ไว้ข้าง ๆ ไฟล์ `dist/DeskBuddy.exe`

**หมายเหตุเรื่องแอนตี้ไวรัส:** ไฟล์ .exe ที่แพ็กด้วย PyInstaller มักโดนแอนตี้ไวรัสเตือนผิดพลาด (false positive) และ Windows SmartScreen อาจเตือนเพราะไฟล์ไม่มีลายเซ็น โปรแกรมนี้หลีกเลี่ยงพฤติกรรมที่น่าสงสัยโดยตั้งใจ คือไม่ใช้ keyboard hook (ใช้ `GetLastInputInfo` ซึ่งรู้แค่ว่ามี input ล่าสุดเมื่อไร ไม่เห็นว่ากดอะไร) ไม่ตั้งตัวเองเข้า Startup เงียบ ๆ และไม่ซ่อนตัว ถ้าจะปล่อยให้คนอื่นโหลด แนะนำให้ตรวจไฟล์ด้วย VirusTotal ก่อน แนบค่า SHA256 ใน Release และแนะนำคนที่รู้จัก Python ให้รันจากซอร์สโดยตรง

## โครงสร้าง

```
main.py                 จุดเริ่มต้น
games.json              รายชื่อเกม
personalities/          ชุดข้อความของแต่ละบุคลิก
deskbuddy/
  engine.py             ตัวตัดสินใจว่าเมื่อไหร่ควรทัก (ไม่ผูกกับ Windows)
  app.py                ประกอบ tray + ลูปตรวจสถานะ + ป๊อปอัป
  ui.py                 หน้าต่างป๊อปอัป (tkinter)
  settings_window.py    หน้าต่างตั้งค่า
  settings_model.py     ตรวจและแปลงค่าจากหน้าตั้งค่า (ไม่ใช้ tkinter)
  winapi.py             ตรวจ idle / หน้าต่าง / กันเปิดซ้ำ (ctypes)
  games.py              ตรวจว่าเกมไหนรันอยู่
  minecraft_log.py      นับการตายจาก latest.log
  storage.py            เก็บสถิติในเครื่อง
  messages.py           ระบบบุคลิก
  autostart.py          เปิดพร้อม Windows
tests/                  ชุดทดสอบ
```

- ให้คุยอิสระได้ผ่าน Gemini API key ของผู้ใช้เอง (เป็นออปชัน)
- บุคลิกเพิ่มเติม
- แอปมือถือที่ซิงก์ข้อมูลกัน
