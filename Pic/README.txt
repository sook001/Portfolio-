วิธีใส่รูปในพอร์ตโฟลิโอ
========================

รูปโปรไฟล์
- ใช้ไฟล์ Pic/Profile 1.png
- เปลี่ยนรูปได้โดยแทนที่ไฟล์เดิม แต่คงชื่อและนามสกุลเดิมไว้

รูปผลงาน
- ใส่ภาพหน้าจอในโฟลเดอร์ Pic/projects โดยใช้ชื่อไฟล์ตามรายการ:

  deskbuddy.png    ภาพหน้าจอโปรแกรม DeskBuddy
  hoshimachi.png   ภาพตัวอย่างเว็บ Hoshimachi Suisei
  nanahoshi.png    ภาพตัวอย่างเว็บ Nanahoshi Nana
  daily-check.svg  ภาพตัวอย่าง Daily Check

เมื่อใช้ชื่อไฟล์และนามสกุลตามรายการ รูปจะแสดงในกรอบให้อัตโนมัติ
ถ้ายังไม่มีไฟล์หรือโหลดรูปไม่สำเร็จ กรอบข้อความตัวอย่างจะแสดงแทน

ถ้าต้องการใช้ไฟล์นามสกุลอื่น ให้แก้ค่า src ของรูปที่ตรงกันใน index.html
ภาพ Hoshimachi และ Nanahoshi ใน Pic/projects เป็นสำเนาของภาพต้นฉบับที่อยู่ใน Pic
